About Justice Portal

An open-access digital repository for Sikkim High Court judgments.

Project Overview

Justice Portal is a web-based platform that provides easy, searchable access to judgments from the Sikkim High Court. The goal is to make legal information transparent and accessible to citizens, legal professionals, and researchers.

The portal indexes over 2,400 case records spanning several decades, enabling search by petitioner name, case number, or judgment year.

Technology Stack

🐍
Python / Flask REST API backend with modular Blueprints
🌐
HTML5 + CSS3 Semantic markup and CSS variables design system
⚛️
React 18 (CDN) Interactive UI components via Babel in-browser transpile
📊
Chart.js (CDN) Year-wise and judge-wise bar charts
🐼
Pandas Data loading, filtering, and aggregation
📁
CSV Data Store 2,400+ judgment records in flat file format
